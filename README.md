# 🎮 Flexbox Quest — Mini Game UI (HTML & CSS Lab)

A responsive, arcade-themed mini-game dashboard interface built entirely using **HTML5** and **CSS3 Flexbox**. This project was developed as a lab assignment focused on mastering CSS layout primitives, the box model, and responsive design without relying on frameworks or CSS Grid.

---

## 📂 Project Structure

The project is cleanly separated into structural and styling layers:

flexbox-quest/
│
